### 问题 2：Vitis HLS 综合时提示 "Synthesis source is empty" 怎么办？

**背景**：点击 C Synthesis 后报错，找不到源代码。

**解决方案**：
- 在 Vitis HLS 左侧 Explorer 中，右键 `Source` 文件夹
- 选择 `Add Files`，将 `rgb2gray.cpp` 添加到 Source 文件夹
- 重新点击 C Synthesis 绿色三角

---

### 问题 3：Vivado 中 "Top module not set" 怎么办？

**背景**：生成 bitstream 时提示没有设置顶层模块。

**解决方案**：
- 在 Sources 窗口中右键 `design_1.bd`
- 选择 `Generate HDL Wrapper`
- 选择 `Let Vivado manage wrapper and auto-update`
- 等待 wrapper 生成后重新 Generate Bitstream

---

### 问题 4：Jupyter 加载 overlay 时报 "Root permissions required" 怎么办？

**背景**：在普通 Jupyter 会话中调用 `Overlay()` 时报权限错误。

**解决方案**：
- 停止当前 Jupyter
- 在 MobaXterm 中执行：
  ```bash
  sudo -i
  cd /home/xilinx/jupyter_notebooks
  jupyter notebook --ip=0.0.0.0 --allow-root
  ```
- 用 root 权限启动的 Jupyter 才能加载 FPGA overlay

---

### 问题 5：Jupyter 加载 overlay 时报 "No Devices Found" 怎么办？

**背景**：使用 root Jupyter 加载 bitstream 时仍报 `RuntimeError: No Devices Found`。

**排查过程**：
1. 检查 `/dev/xdevcfg`：不存在
2. 检查 `/sys/class/fpga_manager`：重启后用 `sudo -i` 启动 Jupyter 后存在 `fpga0`
3. 确认 dmesg 中 `fpga_manager fpga0: writing base.bin to Xilinx Zynq FPGA Manager` 正常

**根本原因**：之前用 `sudo jupyter notebook` 启动时环境变量不完整，PYNQ 无法检测到 fpga_manager。

**解决方案**：
- 使用 `sudo -i` 进入完整 root shell 后再启动 Jupyter
- 启动命令：
  ```bash
  sudo -i
  cd /home/xilinx/jupyter_notebooks
  jupyter notebook --ip=0.0.0.0 --allow-root
  ```

### 问题 6：PYNQ-Z2 需要额外购买什么设备？

**背景**：确定参赛所需的硬件清单。

**决策结果**：
- **必须购买**：罗技 C270i USB 摄像头（约 109 元）
- **推荐购买/已有**：带独立供电的 USB Hub（已确认有联想 thinkplus USB3.0 集线器可用）
- **可选购买**：Grove Buzzer 蜂鸣器（约 13 元，用于声音报警）
- **不需要买**：显示屏（用 Jupyter 在电脑浏览器显示即可）

---

### 问题 7：C270 和 C270i 有什么区别？买哪个？

**背景**：选购摄像头时在 C270 和 C270i 之间犹豫。

**解决方案**：
- C270i 是 C270 的小改款，分辨率、帧率相同
- C270i 外观更新，麦克风略有改进
- 两者在 PYNQ 上都能用，UVC 免驱
- **推荐买 C270i**，价格 109 元很划算
