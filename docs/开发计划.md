## 风险与应对

| 风险 | 影响 | 应对措施 |
|---|---|---|
| USB 摄像头在 PYNQ 上识别不稳定 | 高 | 使用带独立供电的 USB Hub |
| PL 资源不足无法集成所有模块 | 高 | 先保证核心帧差+二值化，形态学可放 PS |
| AXI-Stream 时序问题 | 中 | 先用小分辨率（320×240）验证 |
| 帧率不达标 | 中 | 降低分辨率或优化 PL 流水线 |
| 队友进度不一致 | 中 | 每日同步，及时调整分工 |
