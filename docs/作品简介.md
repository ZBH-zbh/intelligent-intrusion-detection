# 作品简介

## 作品名称

**基于 PYNQ-Z2 的 FPGA 加速智能入侵检测系统**

## 作品背景

随着物联网与边缘计算的快速发展，传统的视频监控系统往往依赖服务器或云端进行图像分析，存在延迟高、功耗大、隐私泄露等风险。尤其在家庭、仓库、机房等对实时性与成本敏感的场景，亟需一套**低延迟、低功耗、可本地部署**的智能入侵检测方案。

本作品以 **PYNQ-Z2（Xilinx Zynq-7020）** 为核心平台，充分发挥其 ARM 处理系统（PS）与 FPGA 可编程逻辑（PL）的协同优势，将运动检测的核心计算卸载到 FPGA 硬件加速，实现实时、高效、可交互的入侵检测与报警。

## 系统组成

- **硬件平台**：PYNQ-Z2 开发板
- **视频输入**：罗技 C270i USB 摄像头（320×240）
- **报警输出**：Grove Buzzer 蜂鸣器 + Jupyter 可视化界面
- **开发工具**：Vivado / Vitis HLS 2022.1、PYNQ v3.0.1、OpenCV

## 核心功能

1. **实时视频采集**：PS 端通过 OpenCV 读取 USB 摄像头视频流。
2. **FPGA 硬件加速运动检测**：PL 端以 AXI-Stream 流水线方式完成 RGB→灰度、帧间差分、阈值二值化、形态学处理。
3. **PS 端智能后处理**：轮廓提取、目标框合并、入侵判断、FPS 显示。
4. **可配置警戒区**：支持在画面任意位置划定矩形警戒区域。
5. **声光报警联动**：目标进入警戒区时，屏幕显示 ALARM，同时 Grove Buzzer 蜂鸣器响起。
6. **Jupyter 交互显示**：使用 ipywidgets 实现流畅的实时画面展示。

## 技术亮点

- **PL/PS 协同架构**：PL 负责计算密集型图像预处理，PS 负责灵活的逻辑判断与交互，充分发挥 Zynq 异构计算优势。
- **HLS 自研 IP 流水线**：使用 Vitis HLS 独立完成 `rgb2gray`、`frame_diff`、`threshold`、`morphology` 四个 IP，统一 32-bit AXI-Stream 接口。
- **AXI DMA + MMIO 驱动**：绕过 Vivado 2022.1 与 PYNQ 3.0.1 的 hwh 解析兼容问题，直接用 MMIO 访问 AXI-Lite 寄存器，稳定可靠。
- **AXI GPIO 蜂鸣器控制**：在自定义 overlay 中扩展 AXI GPIO，实现 Grove Buzzer 的硬件驱动。
- **参数可配置**：阈值、警戒区、目标面积过滤范围等关键参数可在 Python 中灵活调整。

## 创新点

- 将完整的帧差法运动检测链路在低成本 FPGA 上实现硬件加速，达到实时处理帧率。
- 针对 PYNQ-Z2 实际工程中的 hwh 解析缺陷，提出并验证 MMIO 直接寄存器访问的解决方案。
- 设计了“FPGA 预处理 + Python 智能判断 + 硬件蜂鸣器报警”的完整边缘智能闭环。

## 应用前景

本系统可直接应用于：
- 家庭/商铺入侵报警
- 仓库、机房、实验室等重要区域的安全监控
- 低功耗边缘视频分析节点
- 高校 FPGA/嵌入式/计算机视觉教学演示
