# HLS 优化源码副本

该目录保留与队长 IP 相同的函数名、AXI4-Stream 数据宽度和 AXI-Lite 参数接口，但明确固定为项目实际使用的 320×240。

- 不再使用运行时 `width * height` 作为循环边界，目标是消除四个动态乘法器。
- `width` 或 `height` 不等于 320×240 时，仍消费并输出固定 76800 个像素，但输出数据清零；避免写入帧缓冲区之外。
- morphology 暂时保持队长当前 3×3 腐蚀、右下锚点以及前两行/列清零的行为，即 R09-A。
- 原始源码位于 `D:\FPGA2.0\pl\pl\hls`，未被修改。

这些目标必须通过 HLS C 仿真和后续综合报告确认；在 Vivado 中替换 IP 和生成 bitstream 前还需再次确认。
