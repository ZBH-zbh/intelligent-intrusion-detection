## 1. 最快跑通优化成果

只需要使用 `pynq_deploy` 目录。把其中全部文件上传到 PYNQ 的 `/home/xilinx/`，不要只上传 Python 主脚本。

板端校验：

```bash
cd /home/xilinx
sha256sum intrusion_detection_optimized.bit intrusion_detection_optimized.hwh
```

正确值：

- bit：`78e325fcb43c73fe2c45fbe6f0c21a86dcb2db1acc8a50384810f9c954771ee4`
- hwh：`7e5b68b2906ab9995801db006d94fa067833a727075d2588dd689c64a64be716`

摄像头连接 PYNQ-Z2 的 USB-A 口，Grove Base Shield 插在 Arduino 排针上，蜂鸣器模块连接 G1。进入板卡 Jupyter 后，在一个代码单元格中运行：

```python
%run /home/xilinx/pl_motion_detection_optimized.py
```

已验证环境为 PYNQ 3.0.1、Python 3.10.4、OpenCV 4.5.4、NumPy 1.21.5、psutil 5.9.0。不要在该 PYNQ 镜像上随意升级系统 OpenCV、NumPy 或 PYNQ。

## 2. 正式性能对比

以下命令不使用摄像头、显示或蜂鸣器，会重新加载优化 overlay：

```bash
cd /home/xilinx
python3 pynq_compare_motion.py \
  --bitstream /home/xilinx/intrusion_detection_optimized.bit \
  --source synthetic --warmup 20 --frames 200 --repeats 3 \
  --min-seconds 5 --opencv-threads 1 --dma-poll-sleep-us 100 \
  --output-root /home/xilinx/pynq_results
```

正式结果：OpenCV 48.40 FPS，优化 PL 50.18 FPS；效果一致性详见 `性能对比报告.md` 和 `results/pynq_final_20260914_081017`。

## 5. 目录说明

- `pynq_deploy`：上板运行所需的最小完整集合。
- 根目录 Python 文件：算法、实时演示、基准和诊断源码。
- `pl`：队长基线和优化 HLS/Vivado 工程，保留原目录层级以避免工程引用失效。
- `hls_verification`、`vivado_optimization`：测试入口、日志和报告。
- `results`：Windows、PYNQ 中间数据和最终正式数据。
- `captain_baseline_deploy`：队长原版回退包。
- `docs` 不单独设置；中文说明文档集中在根目录，先读本文件、`README.md` 和 `项目交接文档.md`。
- `交付包验证报告.md`：从新目录实际执行的 Python、HLS、Vivado 验证结果。
- `下一任务Agent交接提示词.md`：新建 Codex 任务时整段复制，用于让下一位 Agent 按正确工程和门禁接手。
- `MANIFEST.sha256`：除清单自身外，交付包全部文件的 SHA-256。

## 6. 固定约束

- 分辨率固定 320×240；修改后必须重新生成 bitstream。
- PS→PL 每像素 32-bit，格式 `0x00RRGGBB`。
- PL→PS 每像素 32-bit，低 8 位为二值掩码。
- 使用交接文档中的实际 AXI-Lite 地址和直接 MMIO；不要强行切回 `ip_dict`。
- bit 与 hwh 必须同名并配套使用。

当前已完成 HLS CSim/综合/IP 导出、Vivado 综合/实现/Bitgen、正式板端性能对比，以及约 3 分钟摄像头和 G1 蜂鸣器持续回归。实时显示稳定在 17.1±0.1 FPS，正式无显示核心吞吐为 50.18 FPS。
