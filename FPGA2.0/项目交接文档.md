## 三、硬件连接

| 设备 | 连接位置 | 备注 |
|---|---|---|
| PYNQ-Z2 | 电源 + 网线/串口 | 通过路由器 DHCP 获取 IP |
| 罗技 C270i USB 摄像头 | PYNQ-Z2 USB 口 | 免驱，UVC 协议 |
| Grove Base Shield | 插在 PYNQ-Z2 Arduino 排针上 | — |
| Grove Buzzer | Grove Base Shield 的 **G1** 口 | 黄线 = 信号，对应 D2 = AR2 = U13 |

**上电顺序建议**：
1. 先给 PYNQ-Z2 上电；
2. 等待 Jupyter 可访问；
3. 再插入 Grove Buzzer（避免上电瞬间蜂鸣器误响）。

## 五、关键参数与接口

### 5.1 图像参数

| 参数 | 值 | 说明 |
|---|---|---|
| 分辨率 | 320 × 240 | 在 `pl_motion_detection_buzzer.py` 中设置 |
| PL 二值化阈值 | 30 | `THRESH = 30` |
| 最小目标面积 | 300 | `MIN_CONTOUR_AREA = 300` |
| 最大目标面积 | 50000 | `MAX_CONTOUR_AREA = 50000` |
| 警戒区 | `(85, 45, 150, 150)` | 画面中心区域 `(x, y, w, h)` |

### 5.2 AXI-Lite 寄存器地址

| IP | 基地址 | `width` 偏移 | `height` 偏移 | `threshold` 偏移 |
|---|---|---|---|---|
| frame_diff | `0x40000000` | `0x10` | `0x18` | — |
| morphology | `0x40010000` | `0x10` | `0x18` | — |
| rgb2gray | `0x40020000` | `0x10` | `0x18` | — |
| threshold | `0x40030000` | `0x10` | `0x18` | `0x20` |
| AXI GPIO（蜂鸣器） | `0x40040000` | — | — | — |
| AXI DMA | `0x41E00000` | — | — | — |

- `AP_CTRL` 偏移均为 `0x00`，写 `0x01` 启动 IP。
- 蜂鸣器控制：写 AXI GPIO `0x00` 寄存器的 bit0，`1` 响，`0` 停。

### 5.3 数据格式

- PS → PL：每像素 **32-bit**，格式 `0x00RRGGBB`，总帧大小 `320×240` 个像素。
- PL → PS：返回二值掩码，低 8 位有效，`0` 或 `255`。

## 六、与队友 OpenCV 纯软件版对比要点

队友需要实现一套功能等价的纯软件版本，作为性能对比基准：

| 步骤 | OpenCV 函数 |
|---|---|
| 灰度化 | `cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)` |
| 帧差 | `cv2.absdiff(curr_gray, prev_gray)` |
| 二值化 | `cv2.threshold(diff, 30, 255, cv2.THRESH_BINARY)` |
| 形态学 | `cv2.morphologyEx(mask, cv2.MORPH_CLOSE/Open, kernel)` |
| 轮廓与画框 | `cv2.findContours` + `cv2.boundingRect` + `cv2.rectangle` |
| 报警判断 | Python 判断目标框与警戒区重叠 |

**对比指标**：
- 平均 FPS（连续 100~200 帧）
- CPU 占用（`top` 查看 `python` 进程）
- 检测效果一致性（同一目标框位置、数量）

## 七、已知问题与注意事项

1. **hwh 解析问题**：Vivado 2022.1 生成的 `.hwh` 文件存在 `<MEMORYMAP/>` 为空的问题，导致 PYNQ 的 `ip_dict` 无法识别自定义 IP。已使用 **MMIO 直接寄存器访问** 绕过。
2. **蜂鸣器上电误响**：FPGA 未配置前 PL 管脚浮空/上拉，可能导致蜂鸣器短暂发声；overlay 加载后会恢复正常。
3. **分辨率固定**：PL 端 HLS IP 内部按 320×240 处理，修改分辨率需要重新生成 bitstream。
4. **Grove 口对应关系**：当前使用 G1 = D2 = AR2 = U13，换口需同步修改 `buzzer.xdc`。
